# دامنه و ردیابی نیازمندی‌ها

مبنای کار: مکالمه کاربر، توضیحات پیوست و پروژه Kotlin موجود در payesh_Fixed. فایل توضیحات، شامل ادعاهای حقوقی و فنی دستیار قبلی است؛ این ادعاها منبع رسمی قانون تلقی نشده‌اند.

| نیاز | پیاده‌سازی | شرط و مرز |
|---|---|---|
| داشبورد واقعی و منسجم | WorkspaceApp / WorkspaceRepository | بدون پرونده یا عدد نمایشی؛ تعداد پرونده دریافت‌شده با پرونده جاری متفاوت است |
| استخراج ابلاغ | snapshot.js / Extraction | کارت‌های مشاهده‌شده در سامانه، جدول، grid، data-label و قاب هم‌مبدأ؛ شمارنده‌ها وارد نمی‌شوند |
| صفحه‌بندی | PaginationRunner / next.js | از صفحه و فیلتر فعلی؛ سقف ایمنی ۱۰۰ صفحه؛ توقف در صفحه تکراری، ورود، قالب ناشناخته یا لغو |
| جزئیات و گردش پرونده | استخراج جدول جزئیات و آرشیو evidence | فقط داده‌های قابل مشاهده؛ در صورت نیاز کاربر صفحه جزئیات را باز می‌کند |
| اتصال ابلاغ و پرونده | Reconciler | شماره پرونده و ابلاغ؛ پیوند از ارجاع یکتای گردش ممکن است؛ تعارض هرگز موفق محسوب نمی‌شود |
| تشخیص اقدام | Reconciler / WorkItem | وضعیت صریح اقدام و مدرک نمایش داده می‌شود؛ مشاهده ابلاغ یا پیش‌نویس معادل اقدام نیست؛ تأیید نهایی با وکیل |
| OCR و ورود اسناد | Documents | فارسی/انگلیسی آفلاین؛ PDF متنی یا اسکن و تصویر؛ بازبینی قبل از ثبت؛ سقف حجم و صفحه |
| دریافت PDF ابلاغ | CourtDownload / PortalController | فقط لینک HTTPS رسمی پس از تأیید کاربر؛ نشست موقت، سقف ۲۵ مگابایت، بررسی امضای PDF و ذخیره از طریق انتخاب محل سیستم |
| مواعد | DeadlineEngine / PersianDates | مدت و مبدأ و تعطیلات تأییدشده توسط وکیل؛ جمع روز، پایان تعطیلات و روز اقدام؛ شش ماه شمسی نه ۱۸۰ روز |
| فرصت‌های مشروط | ActionEngine / CalendarTool | جلب و ورود ثالث، تقابل، ایرادات، ارزیابی، اجرای حکم، تمبر و استعلام به شکل پیشنهاد پیگیری؛ قطعیت و شرط را وکیل تعیین می‌کند |
| پیش‌نویس | ActionEngine / TaskDialog | پرکردن مشخصات شناخته‌شده و ویرایش/ذخیره محلی؛ حقیقت پرونده یا مستند قانونی جعل نمی‌شود |
| قرارداد و نرخ‌ها | ContractTool / FeeCalculator | چک‌لیست اختیارات قابل بازبینی و خروجی؛ نرخ‌ها را کاربر از منبع معتبر وارد می‌کند؛ امضا/پرداخت خودکار نیست |
| آماده‌سازی ضمائم | Documents.optimize | تبدیل تصویر به PDF و سقف حجم؛ PDF امضاشده خودکار تخریب یا بازنویسی نمی‌شود؛ TIFF خروجی تولید نمی‌شود |
| تحلیل گردش | ActionEngine.explain | توضیح محدود و احتیاطی؛ دستور مبهم به نتیجه خیالی تبدیل نمی‌شود |
| پس‌زمینه | ReminderWorker | یادآوری محلی تقریبی هر ۱۲ ساعت؛ بدون وعده دورزدن انقضای نشست یا OTP؛ همگام‌سازی واقعی با بازکردن برنامه و نشست معتبر |
| سلامت | HealthScreen / گزارش ذخیره‌شده | شمار رکورد معتبر، تغییر، خطا و پوشش فهرست؛ شکست از موفقیت تفکیک می‌شود |
| امنیت | Vault / CryptoBox / BackupCipher | رمزگذاری، قفل دستگاه، پشتیبان رمزدار، نبود داده شخصی داخل سورس |
| ظاهر | Compose Material 3 / Vazirmatn | راست‌به‌چپ، حالت تاریک، رنگ سبزآبی و طلایی، جست‌وجو و کارت‌های تعاملی |
| GitHub | workflows + wrapper + tests | بیلد debug و release unsigned، آزمون JVM و DOM و lint؛ APK آزمون رابط ساخته می‌شود و اجرای دستگاه در CI جداگانه است |

## چیزهایی که عمداً ادعای پیاده‌سازی کامل آن‌ها نمی‌شود
API رسمی و مجوز همکاری قضایی در ورودی وجود ندارد. خودران بدون حضور کاربر برای OTP/کپچا، بازکردن خودکار ابلاغ جدید، تعیین خودکار کفایت اقدام قضایی، اعمال اختیارات در قرارداد زنده، امضا و ارسال نهایی پیاده‌سازی نشده است. همه پرونده‌ها و همه صفحات ثنا را نیز نمی‌توان بدون آزمون حساب واقعی تضمین کرد. قالب ناشناخته به‌جای ساخت رکورد جعلی گزارش می‌شود.

این بسته سورس قابل توسعه و بیلد است؛ آزمون‌های نرم‌افزاری تضمین نبود مطلق خطا یا تأیید تجاری/حقوقی نیستند.
